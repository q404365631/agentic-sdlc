# Epics

## Epic 1: User Authentication
User stories: US-07
As a user, I can register, login, and reset my password.

## Epic 2: Task Management
User stories: US-01, US-02, US-03
As a user, I can create, edit, delete, and mark tasks as complete.

## Epic 3: Team Collaboration
User stories: US-04
As a user, I can assign tasks to team members.

## Epic 4: Dashboard & Reporting
User stories: US-05, US-06
As a user, I can view and filter tasks on a dashboard.
